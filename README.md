# Сайт Ильи Лозовского

Статичный сайт: `index.html` + папка `img/`. Ничего собирать не нужно.

## Как опубликовать на GitHub Pages
1. На github.com создайте новый публичный репозиторий (например, `ilya-reels`).
2. Нажмите «uploading an existing file» и перетащите **index.html, README.md и папку img** (именно содержимое архива, а не сам архив).
3. Нажмите «Commit changes».
4. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/ilya-reels/`.

Если назвать репозиторий `ВАШ-НИК.github.io`, сайт будет по адресу `https://ВАШ-НИК.github.io/`.

## Как поменять текст и цены
Откройте `index.html` прямо на GitHub (значок карандаша), найдите нужный текст через Ctrl+F, поправьте и нажмите «Commit changes».
- Цены: ищите `10&nbsp;000` и `40&nbsp;000`
- Ссылка на Telegram: ищите `t.me/frogsoill`
